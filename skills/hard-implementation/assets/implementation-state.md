## Task reconciliation

Link to the authoritative `tasks.md`. Record verified IDs and their evidence;
record in-progress IDs, remaining prerequisites, and stale evidence. Do not
duplicate the entire task description list.

## Active work and file ownership

Record current owners and files, or the sequential execution plan.

## Validation and review evidence

Record actual commands, exit results, relevant code revision, review findings,
and limitations. Link larger evidence artifacts instead of copying logs.

## Blockers and open findings

Record task IDs, root cause, evidence, and the action needed. Distinguish local
failures from unavailable external validation. Do not include secrets.

## Next ready action

State the next concrete unit and prerequisites. On resume, verify this against
the actual repository before executing it.
